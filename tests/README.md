# Перевірка таблиці тварин

Регресійні тести для дефекту `ShowAnimalListTest02` з лабораторної роботи № 5.
Потрібні Python 3 і компілятор g++ з підтримкою C++17.

Запуск із кореня репозиторію:

```text
python tests/test_animal_table.py
```

Шлях до компілятора за потреби можна передати через `--compiler`.
Результати та виконуваний файл записуються в `build/tests/`.
Ненульовий код завершення означає помилку компіляції або невдалий тест.

Перевіряються короткі й довгі українські назви, довгі дані в другому записі,
повнота всіх семи полів, вирівнювання роздільників за символами UTF-8,
порожній список, окремий рядок тварини, пошук наявного й відсутнього ID.
Окремо перевіряється, що виведення та пошук не змінюють дані тварин.

Для українських і латинських текстів один символ займає одну позицію.
Ці тести не перевіряють екранну ширину емодзі, комбінованих знаків або табуляції.
